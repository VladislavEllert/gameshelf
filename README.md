# GameShelf — каталог компьютерных игр

Учебный проект по дисциплине «Веб-программирование» (ОмГТУ, 3 семестр), тема №30
«Каталог компьютерных игр». Автор — Эллерт Владислав, группа ПИН-252т.

Сквозной проект из пяти лабораторных: прототипы (ЛР1) → визуальный дизайн в Figma (ЛР2) →
**HTML/CSS-вёрстка (ЛР3, этот этап)** → окружение NGINX + PHP + СУБД (ЛР4) → данные из БД (ЛР5).

## Как открыть

Сборка не нужна: открыть `index.html` в браузере. Все страницы связаны ссылками в шапке.

## Страницы

| Файл | Страница |
|---|---|
| `index.html` | Библиотека: табы статусов, поиск, сортировка, фильтры, сетка карточек, состояние «Ничего не найдено» |
| `game.html` | Карточка игры: обложка, свойства, оценки, переключатель «Мой статус», достижения, описание, заметки |
| `wishlist.html` | Список желаемого: поиск, сортировка, таблица (с 768 px) или карточки (на телефоне) |
| `stats.html` | Статистика: показатели, топ-10 по времени, время по жанрам, распределение статусов |

## Структура

```
index.html, game.html, wishlist.html, stats.html   — страницы
css/
  tokens.css      — переменные дизайна из Figma: цвета, отступы, скругления, шрифты
  base.css        — сброс стилей браузера, шрифт, контейнер
  components.css  — общие компоненты: шапка, подвал, кнопки, поля, табы, статус, карточка игры, панель, график
  pages.css       — раскладка каждой страницы и медиазапросы
js/
  main.js         — меню, фильтрация и сортировка, переключение статуса, заметки
```

## Адаптивность

Подход mobile-first: базовые стили — для телефона (360 px), медиазапросы `min-width`
добавляют раскладку для 768, 1024 и 1440 px — те же ширины, что у макетов в Figma.

## Технологии

HTML5, CSS3 (custom properties, Grid, Flexbox), JavaScript без библиотек, шрифт Inter
(Google Fonts). Обложки игр — CSS-градиенты; настоящие обложки появятся из Steam в ЛР5.
